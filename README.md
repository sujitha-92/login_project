# Figma-inspired Flask Login Page

## Included
- Login page (`/`)
- Create account page (`/signup`)
- Forgot password page (`/forgot-password`)
- Responsive design inspired by your screenshot
- Show/hide password control

## Run on Windows
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `python -m venv venv`
5. Activate with `.env\Scripts\Activate.ps1`
6. Install Flask: `python -m pip install flask`
7. Run: `python app.py`
8. Open `http://127.0.0.1:5000/`

If PowerShell blocks activation, use `python -m pip install flask` and `python app.py` with your installed Python.

## Important
This is a visual/demo project. It does not store users in a database, verify passwords, or send real password reset emails. Production use requires secure authentication, password hashing, CSRF protection, validation, and a real email reset flow. Store a strong Flask secret key outside source code.
